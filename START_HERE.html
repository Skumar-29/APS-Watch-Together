APS Watch Together
Release setup

This project contains the Chrome extension, secure room server, automated test and a Mac package builder that creates a preconfigured ZIP for friends.

Owner setup

  1. Upload this folder to a private GitHub repository.
  2. Deploy render.yaml using Render Blueprint.
  3. Copy the resulting wss://…/ws address.
  4. Double-click Create-Friend-Package.command.
  5. Paste the address and send the generated ZIP.

Friend setup

  1. Unzip the friend package into Documents.
  2. Open chrome://extensions.
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the extracted folder.
  5. Pin APS Watch Together and join the room.
For the best call reliability, add TURN credentials in extension Settings. The movie remains on each person's own streaming account; APS only synchronizes controls and carries the peer-to-peer call.
