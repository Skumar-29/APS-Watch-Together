# APS Watch Together v1.6.1

## Main improvements

- Stable one-person/one-session replacement prevents duplicate tiles and doubled audio when reopening APS, switching OTT tabs, or moving between full and Cinema views.
- Cinema and floating Full Controls handoff now waits for the full panel to confirm restoration before closing the compact view.
- Screen sharing now supports Maximise/Restore and browser Full Screen controls.
- Camera tiles can be clicked to focus one participant, with a one-click Return to gallery action.
- Host participant moderation: mute, ask to unmute, and remove.
- Optional waiting room with host Admit and Reject controls.
- Provider-aware Open host movie button when a friend is on the wrong service or title.
- Chat message toast notifications with an unread badge and click-to-open behaviour.
- Existing Netflix-safe and Prime Video v1.5.1 player bridges remain unchanged.

## Important limitation

Chrome controls the outer frame of normal popup windows. APS uses the cleanest available browser surface, but a fully borderless native floating window is not guaranteed on every Chrome version.
